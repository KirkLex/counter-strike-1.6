# 🎮 NEON STRIKE — Web FPS

**NEON STRIKE** — браузерный 3D-шутер от первого лица, в котором игрок сражается с волнами противников на тактической карте. Проект реализован с использованием HTML, CSS, JavaScript и библиотеки Three.js.

## 📌 О проекте

NEON STRIKE — игровой мини-проект с трёхмерной графикой, интерфейсом в стиле Tactical FPS и динамическим игровым процессом.

### Основные возможности

* **3D-графика** — трёхмерная сцена с освещением, тенями, текстурами и туманом.
* **Игровая карта** — стены, коридоры, укрытия и ящики.
* **Боевая система** — стрельба, перезарядка, отдача оружия и попадания в противников.
* **Арсенал** — пистолет USP-S и автомат AK-47.
* **Система волн** — последовательное появление противников.
* **Игровые показатели** — очки, количество убийств, здоровье, броня и боеприпасы.
* **Интерфейс HUD** — отображение состояния игрока и текущего хода игры.
* **Таблица рекордов** — сохранение и отображение результатов.
* **Игровые состояния** — главное меню, пауза и экран завершения игры.

## 🛠️ Используемые технологии

| Технология              | Назначение                                                                    |
| ----------------------- | ----------------------------------------------------------------------------- |
| HTML5                   | Структура страницы и игровые интерфейсы                                       |
| CSS3                    | Оформление интерфейса, анимации и визуальные эффекты                          |

**Архитектура:** клиентское веб-приложение без обязательного серверного компонента.

## 🚀 Как запустить проект

### Способ 1. Открыть в браузере

1. Скачайте или скопируйте все файлы проекта в одну папку.
2. Убедитесь, что `index.html`, `style.css` и `game.js` находятся в этой папке.
3. Откройте файл `index.html` в современном браузере.
4. Дождитесь загрузки игры и нажмите **«НАЧАТЬ ИГРУ»**.

> Для загрузки Three.js требуется подключение к интернету, поскольку библиотека подключается через CDN.

### Способ 2. Запуск через Visual Studio Code

1. Откройте папку проекта в Visual Studio Code.
2. При необходимости установите расширение Live Server.
3. Нажмите правой кнопкой мыши на `index.html`.
4. Выберите **Open with Live Server**.
5. Игра откроется в браузере по локальному адресу.

**Важно:** Node.js, npm, сборщик и отдельный backend для текущей версии проекта не требуются.

## 🧩 Особенности реализации

* Трёхмерная сцена создаётся средствами Three.js.
* Геометрия карты и игровые объекты формируются программно.
* Текстуры пола, стен, кирпича и дерева генерируются с использованием Canvas API.
* Отображение игры выполняется через WebGL.
* Интерфейс реализован отдельно от 3D-сцены средствами HTML и CSS.
* Игровая логика находится в файле `game.js`.

## 🔧 Требования

* Современный браузер с поддержкой WebGL.
* Поддержка JavaScript.
* Подключение к интернету для загрузки Three.js с CDN.
* Клавиатура и мышь.
